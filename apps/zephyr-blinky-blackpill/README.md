# zephyr-blinky-blackpill

Zephyr app (`find_package(Zephyr)`), board `blackpill_f411ce` (WeAct BlackPill STM32F411CE, LED PC13).
Originally generated by the category's CLion helper (`mcu-ide new zephyr ...`) from the Zephyr blinky sample;
the Zephyr tree under `../../toolchain/zephyr/ws` is never modified.

Everything here uses only this ID (`32_03_zephyr`): toolchain from `../../toolchain/zephyr/env.sh`,
output on idisk03 at the same ID path.

## Command line (from this folder)

```sh
../../scripts/app build . Debug       # or Release; -> <build>/zephyr/zephyr.{elf,bin,hex}
../../scripts/app test .              # host unit tests (tests/, vendored GoogleTest, CTest)
../../scripts/app flash . Debug       # west flash (openocd from the Zephyr SDK, ST-Link)
../../scripts/app monitor /dev/ttyUSB0 115200
```

| Profile | What it builds | Build dir |
|---|---|---|
| Debug | firmware (`CONFIG_DEBUG_OPTIMIZATIONS=y`) | `$ZEPHYR_OUT/apps/zephyr-blinky-blackpill/cmake-build-debug` |
| Release | firmware | `$ZEPHYR_OUT/apps/zephyr-blinky-blackpill/cmake-build-release` |
| Host-Tests | `tests/` with the buildtools gcc + GoogleTest (CTest) | `$ZEPHYR_OUT/apps/zephyr-blinky-blackpill/cmake-build-host-tests` |

## CLion

File > Open > this folder. CLion reads `.idea/cmake.xml` (the three profiles above, same build dirs; each
profile's environment and CMake options point into this ID only).

Run configurations (`.run/`):

| Name | Does |
|---|---|
| Build | `../../scripts/app build . Debug` |
| Flash | `../../scripts/app build . Debug && ../../scripts/app flash . Debug` |
| Monitor | `../../scripts/app monitor` (edit the port in the script text) |
| Debug (OpenOCD + ST-Link) | starts the Zephyr SDK's `openocd`, loads the ELF with CLion's bundled GDB |
| Host tests | runs `tests/` (select the Host-Tests profile first) |

## Files

- `CMakeLists.txt`: firmware build; the `MCU_HOST_TESTS` block at the top switches to the host tests.
- `lib/ringbuf/`: target-independent code; `tests/test_ringbuf.cpp` tests it on the host. `tests/CMakeLists.txt`
  takes `McuHostTests.cmake` and GoogleTest from `../../toolchain/clion/`.
- `mcu-project.json`: settings for the category's `mcu-ide` helper, which also lists this app through a symlink
  in its own `projects/`. Do not regenerate this app with `mcu-ide new --force`: that would point the run
  configurations back at `mcu-ide`.
